# Диабет-контроль

Личный помощник при диабете 1 типа: запасы инсулина и расходников, смены набора и датчика, врачи и анализы, оценка компенсации по данным датчика и помпы.

Веб-приложение (PWA) без сервера и без сборки. Все данные лежат в IndexedDB браузера на устройстве.

## Запуск на компьютере

```bash
node dev-server.mjs
```

Затем откройте http://localhost:5173.

## Что умеет

- **Сегодня.** Четыре колбы с уровнем: инсулин, инфузионный набор, резервуар, датчик. Ниже единый список ближайших дел.
- **Запасы.** Остатки, прогноз «хватит до», дата «пополнить до», журнал смен с отменой, расчёт расходников в поездку.
- **Здоровье.** Эндокринолог и рецепты, анализы, врачи: периодичность, последний раз, запись на дату, история результатов.
- **Сахара.** Время в диапазонах, индекс гликемического риска (GRI), GMI, вариабельность, эпизоды гипо, суточный профиль, разбивка по дням, суточная доза и углеводы. Печать отчёта для врача.
- **Настройки.** Синхронизация с Google Календарём, тема, резервная копия.

## Откуда берутся данные

Официального открытого API нет ни у Ottai, ни у CareLink, поэтому первая версия работает с файлами:

- **Сахара:** любая таблица CSV с датой, временем и значением. Колонки и единицы (ммоль/л или мг/дл) определяются автоматически, их можно поправить перед импортом.
- **Помпа:** CSV-выгрузка CareLink («Отчёты» → «Экспорт данных»). Из неё берутся введённые болюсы, углеводы (в граммах или ХЕ, как в файле), фактическая базальная подача с учётом временных базальных и остановок, заполнение трубки и канюли, заправки резервуара.

Разбор CareLink проверен на настоящей выгрузке MiniMed 720G. Особенности формата описаны в комментарии к `parseCareLink` в `js/importers.js`.

Отчёт Ottai в PDF содержит только итоговые показатели и графики, отдельных измерений в нём нет, поэтому импортировать из него сахара нельзя.

## Google Календарь

Приложение создаёт отдельный календарь «Диабет-контроль» и запрашивает доступ только к нему (scope `calendar.app.created`).

1. В [Google Cloud Console](https://console.cloud.google.com) создайте проект и включите Google Calendar API.
2. Настройте экран согласия OAuth (External) и добавьте себя в тестовые пользователи.
3. Создайте OAuth client ID типа Web application. В Authorized JavaScript origins укажите адрес приложения, например `http://localhost:5173` и адрес хостинга.
4. Вставьте Client ID в настройках приложения и нажмите «Подключить календарь».

Сервера нет, поэтому календарь обновляется, только когда приложение открыто и вход Google активен (около часа после входа).

## Установка на iPhone

Нужен адрес с HTTPS: выложите папку на любой статический хостинг (GitHub Pages, Cloudflare Pages, Netlify). Откройте адрес в Safari, затем «Поделиться» → «На экран Домой». Данные на телефоне и на компьютере хранятся отдельно; переносятся через резервную копию в настройках.

## Устройство кода

| Файл | Назначение |
| --- | --- |
| `js/logic.js` | даты, прогнозы запасов, сроки, список дел |
| `js/metrics.js` | показатели компенсации |
| `js/importers.js` | разбор CareLink и таблиц с сахарами |
| `js/store.js` | хранение, журнал событий, резервная копия |
| `js/gcal.js` | синхронизация с Google Календарём |
| `js/views/*` | экраны |
| `css/app.css` | оформление |

Приложение не подбирает дозы и не заменяет врача.
